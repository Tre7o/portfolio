# Trevor's Portfolio

This is my personal portfolio website — basically a one-page digital introduction to me, my work, and my hobbies, without the awkwardness of small talk in a real-life hallway.

It’s a simple static site built with HTML and CSS, styled to look clean, modern, and just a little bit fancy. Think: portfolio page, but with less corporate jargon and more "yeah, I build things and I like baking too."

## What’s in here
- A hero section introducing me
- A profile summary
- Skills and interests
- Contact links
- A tiny bit of personality, because the internet deserves some flair

## How to run it
Because this is a static site, there’s no complex build process or dependency drama.

```bash
cd "D:\Documents\DevProjects\Web\web-portfolio\portfolio"
python -m http.server 8000
```

Then open `http://localhost:8000/` in your browser.

## Tech stack
- HTML
- CSS
- A few static assets (images, fonts, icons)

No frameworks. No bundlers. No existential crisis.

## Why this exists
This project is basically my online home base: a place to share who I am, what I do, and where people can find me. It’s not trying to be a SaaS product or a startup MVP — it’s just a clean, personal website that does the job and looks good while doing it.
